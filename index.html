Fitbit Personal Health Sync

A personal tool maintained by yyp1156323792-prog to archive the owner's wearable health data and support personal review.

This tool reads health and fitness data from the owner's Google Health account and stores raw responses, daily records, and summaries in the owner's private GitHub repository. GitHub Actions processes the data in the cloud. The owner can also authorize a ChatGPT GitHub connector to read the saved records for personal analysis.

Purpose and access

The tool is for the account owner's personal use. It does not accept public registrations or request access to other people's Google accounts. This public website contains application information and its privacy policy; it has no login, health dashboard, or health data.

The current client reads sleep, resting heart rate, heart rate variability, steps, and daily heart rate aggregates from wearable sources where available. Missing measurements stay missing. Other metrics can require further implementation. Device estimates and summaries are for personal fitness review and are not medical diagnoses.

Permissions

Google authorization requests three read-only scopes:

  • googlehealth.activity_and_fitness.readonly
  • googlehealth.health_metrics_and_measurements.readonly
  • googlehealth.sleep.readonly

The full scope identifiers start with https://www.googleapis.com/auth/. The tool does not write or delete measurements in Google Health.
