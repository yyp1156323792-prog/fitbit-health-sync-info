Fitbit Personal Health Sync

Privacy Policy

Updated 28 October 2026. Maintainer: yyp1156323792-prog.

Personal use and information accessed

This tool is for its owner's personal use. With the owner's Google OAuth consent, it reads wearable sleep, activity, and health measurements through Google Health API. Current data includes sleep sessions and available stages, resting heart rate, RMSSD heart rate variability, steps, and heart rate daily aggregates. Raw responses can contain source metadata and record identifiers needed to trace derived results.

How information is used and shared

The Python client creates a private health archive, daily structured records, and weekly or seven-day summaries. GitHub-hosted Actions runners process this information, and the owner's private GitHub repository stores it. If the owner connects that repository to ChatGPT, the authorized GitHub connector and ChatGPT may process records the owner requests for analysis. A local copy may be used in Obsidian at the owner's direction.

The sync program does not sell health data, use it for advertising, or use it to train generalized AI models. Connected services handle information under their own terms, privacy policies, account settings, and applicable permissions; this page does not promise that those services retain no information. The owner should review each service before connecting the archive.

Fitbit Personal Health Sync's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Credentials and protection

OAuth credentials used by cloud synchronization are stored in GitHub Actions Secrets when configured. Access tokens are used in process memory. Credentials are excluded from the health archive, application source, public pages, artifacts, and application logs. Read-only Google permissions limit the client to reading the consented data. The owner controls access to the private repository and should protect both Google and GitHub accounts.

Retention and deletion

The private archive retains raw responses and derived records until the owner deletes them. Revised records may remain in Git history. Deleting a current file alone does not erase historical commits, copies, provider backups, or information already processed by a connected service. Full deletion requires reviewing those locations and each provider's deletion procedures. Revoking Google consent stops future access but does not automatically delete previously saved records.

Owner controls

  • Revoke this app in the Google Account third-party connections settings.
  • Disable the GitHub workflow and remove its Actions Secrets to stop cloud synchronization.
  • Disconnect ChatGPT's repository access if it is no longer wanted.
  • Delete archived records and address Git history and other copies when removal is required.

This public website

These static pages do not contain health data or OAuth credentials and add no analytics scripts, advertising, login form, or application cookies. If hosted on GitHub Pages, GitHub logs visitor IP addresses for security according to the GitHub Privacy Statement.

Contact and changes

For authorization support, use the support address displayed on the Google consent screen. Public contact is available through the maintainer's linked GitHub profile; do not include health data or credentials in public communications. Material changes to data handling should be reflected in this policy before they take effect.
